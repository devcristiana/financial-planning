# 📊 Planilha Financeira

Calculadora de orçamento mensal feita em HTML, CSS e JavaScript puro, inspirada em uma planilha de controle financeiro do Excel.

## ✨ Funcionalidades

- Cadastro de fontes de renda e despesas
- Cálculo automático de total de renda, total de despesas e saldo
- Indicador visual de porcentagem da renda gasta
- Marcação de despesas como pagas ou pendentes
- Gráfico comparando renda x despesas
- Campo para definir o mês de referência
- Dados salvos automaticamente
- Layout responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3 (sem frameworks)
- JavaScript (vanilla)

## 💡 Sobre o projeto

Este projeto recria a lógica de uma planilha de orçamento mensal usando apenas HTML, CSS e JavaScript, sem depender de bibliotecas ou frameworks. A ideia foi praticar:

- Cálculos em tempo real conforme o usuário edita os dados
- Persistência de dados
- Layout responsivo e design com identidade própria

## 🔮 Melhorias futuras

- Modo escuro
- Histórico de meses anteriores
